# Candidate Verification

Verification is the boundary between a generated representation and a promoted Evidence record.

A candidate is not Evidence merely because it is coherent, useful, or generated by the Runtime.

Promotion requires an observable basis that can be traced back to the source Landscape.

```text
Candidate
   ↓
Verification
   ├── supported → Evidence
   └── unsupported → Candidate remains unpromoted
```

The original Evidence is never rewritten by promotion or rejection.
