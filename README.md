# Shirakami Research

Experimental research landscape for Shirakami OS.

This repository is intentionally separate from the Shirakami OS runtime and foundation repositories.

## Purpose

This repository records experiments concerning:

- Evidence
- Evidence lineage
- Landscape observation
- Delta extraction
- Matome representation
- Dark Question / reverse engineering
- Counter-Evidence
- Re-observation

The repository is an experimental landscape. Unverified hypotheses must remain distinguishable from established evidence.

## Initial experimental flow

```text
Landscape Evidence
        ↓
      Delta
        ↓
Matome Representation
        ↓
   Dark Question
        ↓
 Counter-Evidence
        ↓
 Re-observation
```

## Boundary

Evidence is not rewritten by interpretation.

Matome is a representation layer, not necessarily a source of truth.

YAML is one possible representation format, not a mandatory language.

Research results may later be promoted to Shirakami OS only after observation and verification.
